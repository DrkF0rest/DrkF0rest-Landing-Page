DocAMPP

Lightweight containerized local development environment that bundles Docker, Apache, MySQL, and PHP into a single stack. Eliminates the "works on my machine" problem by providing an identical environment across all development machines with the ease of XAMPP and the power of Docker.

Containerization

Single-command setup with docker-compose. Isolated environment with persistent data, automatic logging, and easy customization.

Web Stack

PHP 8.2+ with essential extensions, Apache 2.4 web server, MySQL 8.0 database, and phpMyAdmin for database management.

Developer Experience

Hot-reload support, custom PHP configuration, environment variables, and comprehensive CLI commands for container management.

Current project / Backend engineer

Dental Presence

QR-based attendance system for SMK Dental Asisten Sekesal Jakarta. Students scan QR codes to check in and out. Teachers monitor attendance and record manually when needed. Admin manages users, schedules, and generates reports.

QR Attendance

Students scan QR codes to check in and out. System records timestamp, enforces 60-second cooldown between check-in and check-out, and auto-marks late arrivals after 06:30.

Role-Based Dashboards

Separate interfaces for Admin, Guru (Teachers), and Siswa (Students). Each role has specific permissions: admins manage data and view reports, teachers record attendance and monitor classes, students scan QR and view their attendance history.

Attendance Management

QR-based and manual attendance recording. Support for status: Hadir (Present), Terlambat (Late), Izin (Excused), Sakit (Sick), Alpa (Absent). Automatic late-marking and manual entry by teachers.

Data & Scheduling

Admin manages users, students, classes, subjects, teaching assignments, and schedules. System stores class data, teacher assignments, lesson schedules, and student information with status tracking.

Monitoring & Reports

Attendance tracking per student and class. Export reports as Excel (.xlsx) or PDF. Filter by date range, class, and status. Admin dashboard shows daily summaries, class statistics, and recent attendance activity.

Session & Security

PHP session-based authentication, password hashing, CSRF token validation, role-based access control, and row-level locking for concurrent attendance recording.

Key features
